# Menu artwork

- `backgrounds/`: full-screen still images or video poster frames.
- `buttons/`: idle, hover, selected, and insensitive button artwork.
- `icons/`: transparent UI icons.
- `panels/`: scalable frames, cards, borders, and overlays.
- `effects/`: particles, masks, noise, light passes, and shader textures.

Design against the project's 1920x1080 virtual canvas. Keep important content
inside safe margins and use transparent PNG or WebP for layered elements.
